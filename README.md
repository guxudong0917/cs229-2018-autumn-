## 简介
笔者差不多花费了50+小时的时间在b站上看完了cs229的视频课和note部分，怎么说呢，它很好地帮助我对机器学习的常见算法有了比较初步的了解，但很多地方究竟是通过什么方法去计算，以及模型的参数更新的具体实现，我仍然是一头雾水。

我曾经非常犹豫要不要去花时间做这么课的assignment和lab部分，因为听闻它们涉及到比较多的数学推导，和纯numpy手撕参数更新的任务，而当今的scikit-learn几乎已经非常完善，一个import,一个fit,一个predict三行就可以解决所有训练与预测的部分。而AI 写代码已经很强了，我或许也根本不需要再去了解如何去实现具体的代码。

所以花时间去了解一些细节真的值得吗?从功利的角度来说，似乎不太值。

但尝试了PS1后，我似乎看到了另一个思考的角度。

简单说吧，每个部分的题型几乎都是这种组成，在一些地方先让你推出参数更新关键部分的数学证明，然后立马做代码任务:用刚刚推出的结论去写代码，立马把公式运用到实际中。

这是一种很强的正反馈，因为可以看见理论真的在和实践紧密结合，而且也极大的加深了我对一些机器学习算法的理解。

正是这种对于知识理解的极大增强，让我决定完成所有的Assignment。尽管它或许在AI时代下一文不值，因为大多代码都可以被一些模糊的提示词+一个世界前沿的AI编程工具所解决。

但是我在理解的过程中却找到了一种很本源的满足，或许是源于人类的好奇心，当我知晓它们为什么可以这样运作的时候，我会觉得我距离理解真实的世界进了一步，在这个过程中我感到幸福。

很庆幸现在还勉强有时间以好奇为理由去学习，总感觉以后这样的日子会越来越少的。



## 添加部分

我计划在原仓库基础上新增 `笔记整理/` 文件夹，用来存放自己的学习笔记、公式推导、作业总结和配图资源。

目前 `笔记整理/` 的结构大致包括：

- `数学基础知识.md`：数学部分总纲。
- `数学知识/矩阵基础.md`：矩阵求导、trace 技巧、Hessian、范数、行列式等基础。
- `数学知识/概率论基础.md`：联合概率、条件概率、贝叶斯公式、期望、方差、协方差、多元高斯、MLE 等。
- `监督学习-线性模型.md`：线性回归、正规方程、局部加权线性回归、逻辑回归、牛顿法。
- `监督学习-GLM与指数族.md`：指数族、GLM 三个假设、均值方差性质、逻辑回归和 Poisson 回归。
- `监督学习-GLA生成式学习算法.md`：生成式学习算法、GDA、朴素贝叶斯。
- `监督学习-SVM支持向量机和核方法.md`：SVM 的函数间隔、几何间隔、软/硬间隔、对偶形式、核函数、核矩阵与 Mercer 条件。
- `监督学习-正则化泛化与交叉验证.md`：正则化的贝叶斯解释、MAP、L1/L2 正则化、泛化误差、Bias-Variance、Double Descent、交叉验证、ERM 与 VC Dimension。
- `imgs/`：笔记配图资源。
