## 简介
笔者差不多花费了42+小时的时间在b站上看完了cs229的大部分视频课(除了神经网络的部分，这一部分之前看过一些资料)和相关note部分。视频质量很高，一个多小时的课程我时常要看2-3个小时，才能勉强明白。我记了厚厚的笔记，上完课我确实大概了解了每个算法在干什么，也可以大致说出来它们是用什么思想去更新，收敛的。但是，课堂上略过了很多具体的计算与代码实现过程，这就导致我对它们的理解，其实还是停留在别人告诉我是这么回事上。

上完视频课，我犹豫要不要去做assignment部分。想做的原因是知道它们涉及到比较多的数学推导，和纯numpy手撕任务，我做完后对细节的理解会大大增强；不想做的原因是scikit-learn几乎已经非常完善，一个import,一个fit,一个predict三行就可以解决所有训练与预测的部分。而在AI的加持下，连调包scikit的过程都可以被抽象了。

从功利的角度来说，AI时代下深入探究算法的细节似乎已经在失去价值。

但最后我还是抱着试一试的心态开始做起了PS1，大不了随时退出嘛。在这其中，我看到了另一个思考的角度。

先简单介绍一下Assignment的组成，针对每个部分的知识点，题型包含了课堂上掠过的一些证明和细节，会让你用数学推导出参数更新的公式，然后再让你在框架上去实现核心的算法部分。

为什么它改变了我的想法，因为我在其中得到了很强的正反馈。很长一段时间，我的学习是没有正反馈的，至少在数学层面是这样，也许我可以拿个不错的高数，线代或概率论成绩，但我并不理解这些公式到底是为了解决我研究方向的什么问题，以致于我需要去学他们。

在这里我才知道一切都是自然而然的，每一个算法是背后都有一个精密的数学证明，而代码是它们的自然衍生。经过上述的证明-实践循环后，我发现每一个算法的透明度在我这都降低了许多，它们不是黑盒，不是别人口中"应当如此"的产物.而是我验证过了后，它们的确如此的信念。

或许是源于人类的好奇心，当我知晓它们的底层原理后，我会有一种很本源的满足感:未知的事物减少，我了解的更多了。

总之，最后我还是把4个assignment全做完了，耗时差不多30个小时(我做的确实有点慢，有些地方卡住了很久)，收获颇丰，至少我现在没有那么害怕矩阵的各种运算和求偏导，GLM/GDA/Kernel/EM/GMM/ICA这几个部分的理解也提升了许多。

结束的时候又想起了最开始选择cs229的原因:学校讲的课太水。没想到最后花费了70+小时的时间去学习它，成了是这学期投入精力最大的一门课。这个过程中，收获应该还是大于遗憾的。




## 添加部分

我计划在原仓库基础上新增 `笔记整理/` 文件夹，用来存放自己的学习笔记、公式推导、作业总结和配图资源。

目前 `笔记整理/` 的结构大致包括：

- `数学基础知识.md`：数学部分总纲。
- `数学知识/矩阵基础.md`：矩阵求导、trace 技巧、Hessian、范数、行列式等基础。
- `数学知识/概率论基础.md`：联合概率、条件概率、贝叶斯公式、期望、方差、协方差、多元高斯、MLE 等。
- `监督学习-线性模型.md`：线性回归、正规方程、局部加权线性回归、逻辑回归、牛顿法。
- `监督学习-GLM与指数族.md`：指数族、GLM 三个假设、均值方差性质、逻辑回归和 Poisson 回归。
- `监督学习-GLA生成式学习算法.md`：生成式学习算法、GDA、朴素贝叶斯。
- `监督学习-SVM支持向量机和核方法.md`：SVM 的函数间隔、几何间隔、软/硬间隔、对偶形式、核函数、核矩阵与 Mercer 条件。
- `监督学习-正则化泛化与交叉验证.md`：正则化的贝叶斯解释、MAP、L1/L2 正则化、泛化误差、Bias-Variance、Double Descent、交叉验证、ERM 与 VC Dimension。
- `无监督学习-KMeans聚类.md`：K-means 的目标函数、算法步骤、收敛性证明、与 EM/GMM 的关系，以及 PS3 图片压缩任务。
- `无监督学习-EM算法与GMM.md`：GMM 的基本思想、EM 下界推导、E-step/M-step、半监督 EM 与 GMM 参数更新。
- `无监督学习-PCA主成分分析.md`：PCA 的最大方差视角、重构误差最小化视角、主成分降维、方差贡献率与应用。
- `无监督学习-ICA独立成分分析.md`：ICA 盲源分离、密度变换、最大似然推导、高斯源失效原因、Laplace 源更新公式与鸡尾酒会问题。
- `imgs/`：笔记配图资源。
