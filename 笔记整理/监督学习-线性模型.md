# 监督学习：线性模型

本页统一记号：$m$ 表示样本数，$n$ 表示特征数；$x^{(i)}$ 表示第 $i$ 个样本，$x_j$ 表示第 $j$ 列特征，$x_j^{(i)}$ 表示第 $i$ 个样本的第 $j$ 列特征；$\hat y$ 表示预测值。默认把截距项写入特征，即 $x_0=1$。

关联：[[矩阵基础]]

## 1. 基础线性回归

线性回归的假设函数是 $h_\theta(x)=\theta_0+\theta_1x_1+\cdots+\theta_nx_n=\theta^Tx$。对第 $i$ 个样本，预测值为 $\hat y^{(i)}=h_\theta(x^{(i)})=\theta^Tx^{(i)}$。

这是二维的线性回归(两个特征):
![[二维线性回归.png|线性回归：用一条直线拟合散点]]

### 从单样本损失推出 SGD 更新

先只看一个样本 $(x^{(i)},y^{(i)})$。单样本平方损失定义为 $J_i(\theta)=\frac12(h_\theta(x^{(i)})-y^{(i)})^2$。

为了对 $\theta_j$ 求导，令误差 $e^{(i)}=h_\theta(x^{(i)})-y^{(i)}$。因为 $J_i(\theta)=\frac12(e^{(i)})^2$，所以由链式法则：

$$
\frac{\partial J_i}{\partial\theta_j}
=e^{(i)}\frac{\partial e^{(i)}}{\partial\theta_j}
=(h_\theta(x^{(i)})-y^{(i)})\frac{\partial h_\theta(x^{(i)})}{\partial\theta_j}
$$

又因为 $h_\theta(x^{(i)})=\sum_{k=0}^n\theta_kx_k^{(i)}$，所以 $\frac{\partial h_\theta(x^{(i)})}{\partial\theta_j}=x_j^{(i)}$。因此：

$$
\frac{\partial J_i}{\partial\theta_j}
=(h_\theta(x^{(i)})-y^{(i)})x_j^{(i)}
$$

梯度下降是沿负梯度方向更新，所以 SGD 的单个参数更新为：

$$
\theta_j:=\theta_j-\alpha(h_\theta(x^{(i)})-y^{(i)})x_j^{(i)}
$$

向量形式为 $\theta:=\theta-\alpha(h_\theta(x^{(i)})-y^{(i)})x^{(i)}$。

更新过程belike寻找一个最低点(局部):
![[梯度下降.png|线性回归：用一条直线拟合散点]]

### 从全样本损失推出 BGD 更新

全样本平均平方损失为：

$$
J(\theta)=\frac{1}{2m}\sum_{i=1}^m(h_\theta(x^{(i)})-y^{(i)})^2
$$

对 $\theta_j$ 求导时，只需要把上面的单样本结果累加并乘上 $\frac1m$：

$$
\frac{\partial J}{\partial\theta_j}
=\frac1m\sum_{i=1}^m(h_\theta(x^{(i)})-y^{(i)})x_j^{(i)}
$$

把所有样本写成矩阵。令 $X\in\mathbb R^{m\times(n+1)}$，每一行是 $(x^{(i)})^T$；令 $Y\in\mathbb R^{m\times1}$，$h(X)=X\theta$。此时 $h(X)-Y$ 是 $m\times1$ 的误差向量。

矩阵乘法 $X^T(h(X)-Y)$ 的第 $j$ 项正好是 $\sum_{i=1}^m(h_\theta(x^{(i)})-y^{(i)})x_j^{(i)}$，所以：

$$
\nabla_\theta J(\theta)=\frac1mX^T(h(X)-Y)
$$

因此批量梯度下降 BGD 更新为：

$$
\theta:=\theta-\alpha\frac1mX^T(h(X)-Y)
$$

如果损失函数使用总损失而不是平均损失，可以省略 $\frac1m$，把它吸收到学习率 $\alpha$ 中。

```python
class PoissonRegression(LinearModel):
    """Poisson Regression.
    Example usage:
        > clf = PoissonRegression(step_size=lr)
        > clf.fit(x_train, y_train)
        > clf.predict(x_eval)
    """

    def fit(self, x, y):
        """Run gradient ascent to maximize likelihood for Poisson regression.  
        Args:
            x: Training example inputs. Shape (m, n).
            y: Training example labels. Shape (m,).
        """
        # *** START CODE HERE ***

        #先初始化theta

        n=x.shape[1]

        m=y.shape[0]

        self.theta=np.zeros(n)

        for i in range(self.max_iter):
        
            h=np.exp(x@self.theta)#m
            update=self.step_size*(x.T@(y-h))/m
            
            if np.linalg.norm(update,ord=1)<self.eps:
                print(f"更新值小于{self.eps},停止更新")
                break
            self.theta+=update
        # *** END CODE HERE ***

    def predict(self, x):

        """Make a prediction given inputs x.
        Args:
            x: Inputs of shape (m, n).
        Returns:
            Floating-point prediction for each input, shape (m,).
        """

        # *** START CODE HERE ***
        h=np.exp(x@self.theta)
        return h

        # *** END CODE HERE ***
```

### BGD 与 SGD

BGD 每次更新都使用全部 $m$ 个样本，方向更稳定；当目标函数凸且学习率合适时，可以收敛到全局最优。但每次更新代价高，数据量大时更新慢。

SGD 每次只用一个样本或一个 mini-batch 更新，单步代价低，下降快；但更新方向噪声大，可能不会精确收敛到最小点，而是在最优点附近震荡。SGD 中相邻两次更新使用的样本可能不同，所以每次更新时的 $\theta$ 会沿着更抖的路径移动；BGD 每轮使用整体梯度，下降轨迹更平滑。

## 2. 正规方程

正规方程用于直接求解最小二乘的闭式解。这里使用总损失 $J(\theta)=\frac12\sum_{i=1}^m(\theta^Tx^{(i)}-y^{(i)})^2$，不影响最优点。

把逐样本残差堆成向量，得到 $X\theta-Y$。于是：

$$
J(\theta)=\frac12(X\theta-Y)^T(X\theta-Y)
$$

令 $r=X\theta-Y$，则 $J(\theta)=\frac12r^Tr$，且 $dr=X\,d\theta$。用微分法(用链式求导更快)：

$$
dJ=r^Tdr(解释:=\frac12(r^Tdr+dr^Tr),有因为dr^Tr是标量,所以它等于转置的r^Tdr)=r^TX\,d\theta=(X^Tr)^Td\theta
$$

$$
\nabla_\theta J(\theta)=X^T(X\theta-Y)
$$

令梯度为 0：                                $X^T(X\theta-Y)=0$

展开得到正规方程：		            	$X^TX\theta=X^TY$

若 $X^TX$ 可逆，则闭式解为：     $\theta=(X^TX)^{-1}X^TY$

注意不能从 $X^T(X\theta-Y)=0$ 直接消去 $X^T$，因为 $X^T$ 通常不是方阵，也不一定可逆。正规方程的几何含义是：残差 $X\theta-Y$ 与 $X$ 的每一列特征方向正交。

## 3. 局部加权线性回归

局部加权线性回归的直观想法是：预测某个查询点 $x$ 时，离它越近的训练样本越重要，应该给更大的权重；离它越远的训练样本影响更小。

对当前查询点 $x$，第 $i$ 个训练样本的权重为：

$$
w^{(i)}=\exp\left(-\frac{\|x^{(i)}-x\|_2^2}{2\tau^2}\right)
$$

其中 $\tau$ 是 bandwidth。$\tau$ 越小，模型越局部，可能更灵活也更容易抖；$\tau$ 越大，模型越平滑，逐渐接近普通线性回归。

加权损失为：

$$
J(\theta)=\frac12\sum_{i=1}^m w^{(i)}(\theta^Tx^{(i)}-y^{(i)})^2
$$

令 $W=\mathrm{diag}(w^{(1)},\dots,w^{(m)})$，则：

$$
J(\theta)=\frac12(X\theta-Y)^TW(X\theta-Y)
$$

同样令 $r=X\theta-Y$。因为 $W$ 是对角矩阵，所以 $W=W^T$。微分为：

$$
dJ=\frac12d(r^TWr)=r^TW\,dr=r^TWX\,d\theta
$$

整理成 $dJ=(\nabla_\theta J)^Td\theta$，得到 $\nabla_\theta J=X^TWr=X^TW(X\theta-Y)$。

令梯度为 0：

$$
X^TW(X\theta-Y)=0
$$

得到加权正规方程：

$$
X^TWX\theta=X^TWY
$$

若 $X^TWX$ 可逆，则 $\theta=(X^TWX)^{-1}X^TWY$。

局部加权线性回归通常没有一个固定的全局 $\theta$。每预测一个新的查询点 $x$，都要重新计算一套权重 $W(x)$，再临时求出对应的 $\theta(x)$，最后用 $\hat y=x^T\theta(x)$ 预测。



```python
  

class LocallyWeightedLinearRegression(LinearModel):

    """Locally Weighted Regression (LWR).
    Example usage:
        > clf = LocallyWeightedLinearRegression(tau)
        > clf.fit(x_train, y_train)
        > clf.predict(x_eval)
    """

    def __init__(self, tau):

        super(LocallyWeightedLinearRegression, self).__init__()
        self.tau = tau
        self.x = None
        self.y = None

    def fit(self, x, y):

        """Fit LWR by saving the training set.
        """
        self.x=x
        self.y=y

    def predict(self, x):

        """Make predictions given inputs x.
        Args:
            x: Inputs of shape (m, n).
        Returns:
            Outputs of shape (m,).
        """
        # *** START CODE HERE ***
        m=x.shape[0]
        pred=[]
        for i in range(m):
            given_x=x[i].reshape(1,-1)#变为1,n 这样就可以广播
            
            w = np.exp(-(np.linalg.norm(self.x-given_x,ord=2,axis=1)**2)/(2*self.tau**2))
            W=np.diag(w)/2

            theta=np.linalg.solve(self.x.T@W@self.x,self.x.T@W@self.y)
            temp_pred=theta.T@x[i]
            pred+=[temp_pred]

        result=np.array(pred)
        return result
        # *** END CODE HERE ***

```

## 4. 逻辑回归

逻辑回归用于二分类。它先计算线性打分 $\theta^Tx$，再用 sigmoid 函数压到 $(0,1)$。假设函数为 $h_\theta(x)=g(\theta^Tx)$，其中 $g(z)=\frac{1}{1+e^{-z}}$。因此 $h_\theta(x)$ 可以解释为 $p(y=1\mid x;\theta)$。

![[sigmoid.png|sigmoid 函数：把实数压到 0 到 1 之间]]

因为 $y\in\{0,1\}$，所以可以用 Bernoulli 分布统一写：

$$
p(y\mid x;\theta)=h_\theta(x)^y(1-h_\theta(x))^{1-y}
$$

对 $m$ 个独立样本，似然函数为：

$$
L(\theta)=\prod_{i=1}^m h_\theta(x^{(i)})^{y^{(i)}}(1-h_\theta(x^{(i)}))^{1-y^{(i)}}
$$

取 log-likelihood：

$$
\ell(\theta)=\sum_{i=1}^m\left[y^{(i)}\log h_\theta(x^{(i)})+(1-y^{(i)})\log(1-h_\theta(x^{(i)}))\right]
$$

最大化 $\ell(\theta)$ 等价于最小化平均负对数似然：

$$
J(\theta)=-\frac1m\sum_{i=1}^m\left[y^{(i)}\log h_\theta(x^{(i)})+(1-y^{(i)})\log(1-h_\theta(x^{(i)}))\right]
$$

### 一阶导

先看单个样本的损失 $J_i(\theta)=-y^{(i)}\log h-(1-y^{(i)})\log(1-h)$，其中 $h=h_\theta(x^{(i)})$。

先对 $h$ 求导：

$$
\frac{\partial J_i}{\partial h}
=-\frac{y^{(i)}}{h}+\frac{1-y^{(i)}}{1-h}
=\frac{h-y^{(i)}}{h(1-h)}
$$

再对 $\theta_j$ 求 $h$ 的导数。令 $z=\theta^Tx^{(i)}$，$h=g(z)$。因为 $g'(z)=g(z)(1-g(z))=h(1-h)$，且 $\frac{\partial z}{\partial\theta_j}=x_j^{(i)}$，所以：

$$
\frac{\partial h}{\partial\theta_j}=g'(z)x_j^{(i)}=h(1-h)x_j^{(i)}
$$

链式法则给出：

$$
\frac{\partial J_i}{\partial\theta_j}
=\frac{\partial J_i}{\partial h}\frac{\partial h}{\partial\theta_j}
=\frac{h-y^{(i)}}{h(1-h)}h(1-h)x_j^{(i)}
=(h-y^{(i)})x_j^{(i)}
$$

对所有样本取平均：

$$
\frac{\partial J(\theta)}{\partial\theta_j}
=\frac1m\sum_{i=1}^m(h_\theta(x^{(i)})-y^{(i)})x_j^{(i)}
$$

矩阵形式为：

$$
\nabla_\theta J(\theta)=\frac1mX^T(h(X)-Y)
$$

### 二阶导与 Hessian

一阶导的第 $j$ 项为 $\frac{\partial J}{\partial\theta_j}=\frac1m\sum_{i=1}^m(h_i-y^{(i)})x_j^{(i)}$，其中 $h_i=h_\theta(x^{(i)})$。

继续对 $\theta_k$ 求偏导。因为 $y^{(i)}$ 和 $x_j^{(i)}$ 都不依赖 $\theta$，只有 $h_i$ 依赖 $\theta$：

$$
H_{jk}
=\frac{\partial^2J}{\partial\theta_j\partial\theta_k}
=\frac1m\sum_{i=1}^m\frac{\partial h_i}{\partial\theta_k}x_j^{(i)}
$$

而 $\frac{\partial h_i}{\partial\theta_k}=h_i(1-h_i)x_k^{(i)}$，所以：

$$
H_{jk}
=\frac1m\sum_{i=1}^m h_i(1-h_i)x_j^{(i)}x_k^{(i)}
$$

这个元素形式可以还原成矩阵形式。令 $D\in\mathbb R^{m\times m}$ 为对角矩阵，且 $D_{ii}=h_i(1-h_i)$。由于 $(X^TDX)_{jk}=\sum_{i=1}^m x_j^{(i)}D_{ii}x_k^{(i)}$，所以：

$$
H=\nabla_\theta^2J(\theta)=\frac1mX^TDX
$$

因为 $D_{ii}\ge0$，所以对任意向量 $z$，有 $z^THz=\frac1m(Xz)^TD(Xz)=\frac1m\sum_iD_{ii}((Xz)_i)^2\ge0$。因此 Hessian 是 PSD(半正定矩阵)，逻辑回归的负对数似然是凸函数。

## 5. 牛顿法
![[R-C.png|线性回归：用一条直线拟合散点]]

上图的纵轴是损失函数的一阶导，通过牛顿法让它快速逼近0。

牛顿法是一种快速更新参数的方法。它不仅使用一阶梯度，还使用二阶 Hessian 来近似当前函数的局部形状，因此在条件合适时收敛很快。

最小化目标 $J(\theta)$ 时，牛顿法更新为：

$$
\theta:=\theta-H^{-1}\nabla_\theta J(\theta)
$$

实际代码里通常不要显式求逆，而是解线性方程 $H\Delta=\nabla_\theta J(\theta)$，然后令 $\theta:=\theta-\Delta$。

以逻辑回归为例，第四部分已经推到：

$$
\nabla_\theta J(\theta)=\frac1mX^T(h(X)-Y)
$$

以及：

$$
H=\frac1mX^TDX
$$

其中 $D_{ii}=h_\theta(x^{(i)})(1-h_\theta(x^{(i)}))$。所以牛顿法的一步更新为：

$$
\theta:=\theta-\left(\frac1mX^TDX\right)^{-1}\left(\frac1mX^T(h(X)-Y)\right)
$$

这里的 $\frac1m$ 可以在求解线性方程时相互抵消，但保留它有助于和损失函数定义对应。

### 代码示例

```python
class LogisticRegression(LinearModel):

    """Logistic regression with Newton's Method as the solver.
    Example usage
        > clf = LogisticRegression()
        > clf.fit(x_train, y_train)
        > clf.predict(x_eval)
    """
    
    def fit(self, x, y):

        """Run Newton's Method to minimize J(theta) for logistic regression.
        Args:
            x: Training example inputs. Shape (m, n).
            y: Training example labels. Shape (m,).
        """
        # *** START CODE HERE ***
        #先初始化theta
        n=x.shape[1]
        m=y.shape[0]
        self.theta=np.zeros(n)

        # 这里是一次把所有的样本都放进去迭代

        for i in range(self.max_iter):

            f=x@self.theta #m,
            h=1/(1+np.exp(-f))
            J=-np.mean(y*np.log(h)+(1-y)*np.log(1-h))

            if self.verbose:
                print(f"loss:{J}")

            J_grad=(x.T@(h-y))/m

            Hessian=(x.T@np.diag(h*(1-h))@x)/m # (n,n)
            #更新是要求Hessian的逆与J_grad矩阵相乘，下面求解x，Hessian@x=J_grad，故满足

            update=self.step_size*np.linalg.solve(Hessian,J_grad) #(n,)
            if np.linalg.norm(update,ord=1)<self.eps:
                print(f"更新值小于{self.eps},停止更新")
                break
            self.theta-=update
```
